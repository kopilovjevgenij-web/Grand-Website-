# GRAND — сайт ресторана, бара, банкетов и отеля (Даугавпилс)

Статический сайт на чистых HTML5 / CSS3 / vanilla JS, без фреймворков и сборки.
Сайт на трёх языках: **латышский (основной, в корне)**, русский (`/ru/`) и английский (`/en/`).

## Структура проекта

```
/
├── index.html, menu.html, hotel.html   # LV — основной язык (корень сайта)
├── ru/index.html, ru/menu.html, ru/hotel.html   # RU
├── en/index.html, en/menu.html, en/hotel.html   # EN
├── css/style.css         # общие стили (одни на все языки)
├── js/main.js             # навигация, анимации, формы (тексты форм — из I18N в этом файле)
├── js/reviews.js          # массив реальных отзывов (общий для всех языков, тексты не переводятся)
├── images/                # фото (сейчас — CSS-заглушки, см. images/README.md)
├── favicon.svg
├── robots.txt
└── sitemap.xml            # включает все 9 URL с hreflang-альтернативами
```

### Как добавить/поменять переводы

- Тексты каждой языковой версии — прямо в соответствующем HTML-файле (структура и CSS-классы у всех трёх языков идентичны, отличается только текст и внутренние ссылки с префиксом `/ru/` или `/en/`).
- Переключатель языков (`.lang-switch` в шапке) на каждой странице жёстко ведёт на ту же страницу на другом языке — при добавлении новой страницы не забудьте прописать все три ссылки на ней и добавить взаимные ссылки в остальных двух языковых версиях.
- Отзывы (`js/reviews.js`) намеренно показываются на языке оригинала (в основном русский) на всех трёх версиях сайта — переводить чужие отзывы мы не стали, только подпись над блоком у каждого языка своя.
- Тексты форм (сообщения валидации, статусы отправки) — в объекте `I18N` в начале `js/main.js`, язык определяется по `<html lang="...">`.

## Деплой

Сайт полностью статический — специальный билд не нужен.

### Vercel
1. Импортируйте репозиторий на [vercel.com](https://vercel.com/new).
2. Framework preset — **Other** (или "No framework").
3. Build command — оставить пустым, Output directory — `.` (корень проекта).
4. Deploy.

### Netlify
1. "Add new site" → "Import an existing project".
2. Build command — оставить пустым, Publish directory — `.`.
3. Deploy.

### Обычный хостинг
Просто загрузите все файлы проекта в корень сайта (по FTP/панели хостинга).

## Что нужно заменить перед запуском (плейсхолдеры)

### 1. Фотографии
Сейчас вместо фото — тёмно-золотые CSS-заглушки с иконкой и подписью нужного имени файла.
Список всех необходимых файлов и инструкция — в `images/README.md`.

### 2. Ссылки на внешние сервисы и соцсети — уже подставлены
Booking.com, Bolt Food, Wolt, Instagram, Facebook, e-mail и номер WhatsApp уже вписаны
в `index.html`, `menu.html`, `hotel.html` и `js/main.js` по данным из открытых источников
(страницы заведения на этих сервисах). **Перед запуском стоит перепроверить:**
- **WhatsApp** (`WHATSAPP_NUMBER` в `js/main.js`, сейчас `37122033449`) — номер сформирован
  из опубликованного телефона ресторана. Убедитесь, что именно на нём подключён
  WhatsApp Business — если нет, замените номер.
- **Wolt** — сейчас стоит ссылка на общий каталог доставки по Даугавпилсу
  (`https://wolt.com/en/lva/daugavpils`), так как отдельной карточки GRAND в Wolt на
  момент сборки сайта не нашлось. Как только появится прямая карточка — замените ссылку.
- **Написание бренда** — на сайте используется `GRAND` / `GRAND Restaurant & Hotel`;
  на Booking.com и Facebook встречается вариант `GRAND Restaurant&Hotel` (без пробелов
  вокруг `&`) — если для вас это принципиально, дайте знать, приведём к единому виду.
- Часы работы, состав завтраков, парковка, трансфер, ночной клуб — эти детали стоит
  сверить с текущей практикой заведения перед публикацией (в разделах Booking.com
  упоминаются бесплатная парковка, платный трансфер из аэропорта и ночной клуб —
  на сайте пока не отражены, скажите, если их нужно добавить).

### 3. Приём форм (бронирование стола, банкет, номер в отеле)
Сайт статический, без бэкенда — для отправки писем с форм подключите бесплатный
сервис приёма форм, например:
- [Formspree](https://formspree.io) — endpoint вида `https://formspree.io/f/xxxxxxx`
- [Web3Forms](https://web3forms.com) — endpoint `https://api.web3forms.com/submit` + access key в теле запроса

В `js/main.js`:
```js
var FORM_ENDPOINT = "";
```
Впишите свой endpoint/ключ. Пока переменная пустая, формы показывают сообщение
с предложением отправить заявку через WhatsApp (кнопка уже автоматически
подставляет данные из формы в текст сообщения).

### 4. AI чат-бот (следующий этап)
В футере каждой страницы есть блок:
```html
<div id="chat-widget-placeholder"></div>
```
Сюда позже встраивается виджет AI-чат-бота (интеграция с Facebook/WhatsApp) —
отдельный этап проекта, вне рамок текущего сайта.

### 5. Домен в мета-тегах
В `<head>` каждой страницы указаны `canonical`, `og:url` и `og:image` со заглушечным
доменом `https://grand-daugavpils.lv`, также в `robots.txt` и `sitemap.xml`.
Замените на реальный домен после подключения.

## Технические детали

- Адаптивная вёрстка (mobile-first), проверено на 375px / 768px / 1440px.
- Анимации появления секций при скролле — на `IntersectionObserver`, без внешних библиотек.
- Валидация форм — на vanilla JS (`js/main.js`), обязательные поля, проверка дат.
- SEO: уникальные `title`/`description`/Open Graph на каждой странице, `sitemap.xml`, `robots.txt`, `favicon.svg`.
- Карта на странице контактов — Google Maps embed по адресу Varšavas iela 43B, Даугавпилс (без API-ключа).
